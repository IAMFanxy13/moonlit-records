# Moonlit Records 当前最新版逻辑

本文档与压缩包中的源码对应，用于把项目交给 GPT 或其他开发者继续增量开发。不要推倒重写，也不要擅自增加用户操作复杂度。

## 1. 产品目标

Moonlit Records 是一台由电脑键盘控制的自由钢琴，同时用歌词、字母、左手星标和时值提示辅助普通人弹唱。

核心原则：

- 用户的真实按键只决定“什么时候产生下一个音”，系统不自动演奏下一音。
- 歌曲模式由谱面负责音高、复音、力度、目标时值、衔接与自然释放。
- 自由弹奏仍保持物理键盘按下起音、松开自然释放。
- 操作尽量像打字，但输出可以是多音、和弦化、双手化的钢琴织体。

## 2. 当前键位

- `A–Z`：歌词右手事件。每个歌词单位下方显示对应首字母；按错字母仍发出自由钢琴音，但歌曲游标不前进。
- `Space`：左手低音或和声事件。可以与右手字母同一事件同时要求，也可以出现在相邻歌词事件之间。
- 当一条自动编配的歌词句采用“两个字之间独立 Space”时，该句不再混入 `字母 + SPACE` 合并提示；星标亮起时只需单独按 Space。
- `Shift`：无歌词的右手/间奏事件。左右 Shift 在运行时统一为同一个演奏键。
- `1–0`：不再承担歌曲推进；仅保留旧谱兼容边界。旧谱数字事件会在归一化后转换成歌词首字母或 Shift。
- 不使用浏览器 keyboard repeat；同一物理键必须真实松开后才能再次触发。

## 3. 一字一音、一字多音与重复歌词

歌词显示层和音符事件层分开：一个 `LyricToken` 可以拥有一个或多个右手 `NoteEvent`。

- 一字一音：例如“你”按 `N`。
- 一字多音：例如“爱”有三个右手音，输入为 `A → A → A`，每一次都必须真实松开再按。
- 屏幕始终只显示一个“爱”，其下方显示三个小圆点：未到为空心、当前点发亮、完成点填充。
- 真实重复歌词“爱爱爱”仍显示三个独立的“爱”，输入也是 `A → A → A`，但它们是三个独立 `LyricToken`，不会被合并。
- 插在一字多音之间的左手 `Space` 或无歌词右手 `Shift` 不属于歌词 token，不会增加歌词圆点数量，也不会被改写成歌词字母。

## 4. 歌词与字母显示

- 当前整句歌词保持单行、整体居中，并动态缩放以尽量完整显示。
- 当前句中每个可演奏歌词单位下方都持续显示对应字母，便于提前看见后续按键。
- 当前字母高亮；已完成字母变暗；未到字母保持可见。
- 英文歌词以单词为歌词单位，使用单词首字母。

## 5. Space 左手星标

Space 使用歌词上方的一行菱形星标，不改变歌词布局。星标只允许四种位置：

1. 第一个歌词之前：先按 Space，再进入歌词。
2. 某个歌词正上方：Space 与该字母属于同一时间位置，可同时按。
3. 相邻两个歌词的严格中点：先按左边字母，再按 Space，再按右边字母。
4. 最后一个歌词之后：唱完/弹完最后一个字后再按 Space。

句首和句尾的独立 Space 会在星标旁明确显示 `BEFORE LINE` / `AFTER LINE`，不要求用户仅凭位置猜测。句中的独立 Space 按下后，共用时值条会显示 `LEFT HAND · BETWEEN LYRICS` 并按谱面时值缩短；该进度只是声音时值提示，不评分，也不要求用户精准松键。

状态：

- 空心暗淡：未来提示。
- 金色发亮并显示 `SPACE`：当前应按。
- 熄灭/极暗：已经完成。

位置由谱面 onset 和歌词 token anchor 计算；相邻歌词之间始终投影到几何中点，不使用容易造成歧义的任意偏移。

## 6. 同时双手事件

一个歌曲事件可以同时包含：

- `right`：由歌词字母或 `Shift` 触发的右手旋律/复音手势。
- `left`：由 `Space` 触发的左手低音/和声手势。

当同一事件同时包含左右手时，两个目标都必须真实按下，事件才完成并推进。两只手可以有极短先后差，不要求机器评分式的绝对同步。每个键盘按键背后可以触发一个音，也可以触发多个真实钢琴音组成的 voicing。

## 7. 歌曲游标与按键状态

- 正确 `keydown`：立即起音并记录该事件的已完成手部；所有所需手部都完成后，Score Cursor 立即开放下一事件，不等待 `keyup`。
- `keyup`：只结束该物理键的 ownership；歌曲正确音的音乐释放由谱面与演奏引擎管理，不直接硬切声音，也不推进游标。
- 上一个键未松时可以按下一个正确键，多个 voice 可以短暂重叠以形成连奏。
- 错误键：发出该键自己的自由钢琴音，不推进歌曲、不改变当前等待目标。
- pause、restart、replay、页面失焦和隐藏时会释放并清理所有活动 handle，避免卡音。

## 8. 时值、节奏与慢速输入

- 用户不需要精确控制松键时刻。
- 歌曲正确音在 `keydown` 后按谱面 duration、当前跟随速度、下一个真实正确按键、休止和句界共同安排释放。
- 用户按得慢时，系统不会自动产生下一音，也不会无限吊住上一音；到合理目标时值后进入自然衰减。
- 用户按得快时，相邻音可以有受控 overlap，形成 legato，而不是一个音一个音硬切。
- 页面下方时值条只表示“这个音乐事件预计持续多久/何时准备下一个”，不评分，也不要求用户按条松键。
- `human-tempo-follower` 根据用户真实的正确按键间隔估计舒适速度，用于缩放后续释放与提示，但不替用户自动改节奏或自动起音。

## 9. 钢琴音频

- 使用 Tone.js `Sampler` 播放本地 Salamander 钢琴采样。
- 四套 voice profile：Felt/Warm、Concert、Studio/Bright、Upright；切换音色作用于整台钢琴，包括自由弹奏键。
- 每次物理 `keydown` 只 attack 一次；浏览器 repeat 不会重复触发 sample。
- 每次 attack 建立独立音频 handle；多键和多音可以并存，松开一个键不会误停其他 voice。
- 正确歌曲音使用谱面目标时值和 release plan；自由音/错误音在真实 `keyup` 后自然 release。
- 正确歌曲中的独立字母与独立 `Shift` 如果原谱只有一个音，会自动演奏“主旋律＋较轻八度”；主旋律始终最强，不改变音高辨识度。
- 正确歌曲中的独立 `Space` 如果原谱只有一个低音，会自动展开为“根音＋五度＋八度”的开放低音手势；自动编配的独立左手采用四音开放和声，已有的人工多音左手和弦保持原样。
- 显式 `gestureType: block` 仍然只演奏谱面写明的音；错误键和暂停时的自由钢琴仍对应真实单键，不被自动和弦化。
- 音色链包含 velocity、低通滤波、damper release、房间混响、尾音以及句间 resonance 管理。歌曲结束后等待余音彻底完成，再进入完成页。

## 10. 曲谱格式与兼容

- 支持已有本地曲库。
- 支持 `MOONLIT-SCORE/1` 旧格式并在内存中升级。
- 支持 `MOONLIT-SCORE/2` 声明式 JSON，能够描述左右手、同一事件的多音、力度、时值、articulation、harmony、pedal intent 和 role。
- Score/2 的歌词续音 `subIndex` 只按真实歌词右手事件计数；中间的 Space 或无歌词 `Shift` 不参与计数。
- 具体格式参见 `docs/moonlit-score-2-authoring-guide.md` 和 `docs/gpt-piano-arrangement-prompt.md`。

## 11. 本地运行

要求 Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

默认打开 `http://localhost:3000/`。

验证命令：

```bash
npx tsc --noEmit
npm run lint
npm test -- --run
npm run build
node --test tests/rendered-html.test.mjs
```

## 12. 关键源码入口

- `app/components/PlayerShell.tsx`：物理键盘输入、音频 handle、时值与生命周期。
- `app/lib/player-machine.ts`：歌曲游标、左右手 part、错误键与推进规则。
- `app/components/LyricStage.tsx`：单行歌词、每字字母、多音圆点、Space 星标。
- `app/lib/left-hand-cues.ts`：左手星标的四类位置和投影。
- `app/lib/song-normalizer.ts`：旧曲兼容、LyricToken 与事件归属、一字多音首字母归一化。
- `app/import/moonlit-score-v2.ts`：Score/2 解析、校验与导入。
- `app/audio/piano-engine.ts`：采样器、多音 handle、attack/release 与音色通道。
- `app/audio/piano-voices.ts`：各钢琴音色的声学参数。
- `app/lib/piano-performance.ts`：目标音长、释放和演奏衔接策略。
- `app/lib/phrase-resonance.ts`：句内连奏、共鸣 voice 和收句清理。
